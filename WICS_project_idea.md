# UArizona WICS Project Idea
___

## Intro
Sometimes we would we like to put some skills or libraries on our resume, (for example, _APIs, MySQL, React.js, Web server, appealing UI design_), butafraid of not really knowing it.
A way to demonstrate our skills or we know its usage is through projects. It is good add-on to our resume and it is great evidence to show the recruiter.

## How?
Developing a project is often hard, and pulling up different skills is even more hard! That's fine! We will take care of it. Providing lessons and steps on building
a full stack projects. Tentative steps could be:

1. Read large-scale project
+ Potential questions: there are so many layers of architecture, how can I extract the most useful information from documentation?
  > Additionally, it is good demonstrate the recruiter you know how to read a large-scale project!

2. Developing easily understandable documentation
+ Although AI can be the one writting documentation, how can I make sure the documentation correctly reflects code instead of hallucination?
+ Is the documentation readable, is it for human or AI?

3. Using AI in producing sustanale code.
